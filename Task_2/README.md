# Task 2 - Customer Churn Analysis

## Objective
Analyze customer churn data using Power BI to identify factors affecting customer retention.

## Dataset
Telco Customer Churn Dataset (Kaggle)

## Tools Used
- Power BI
- Microsoft Excel

## Dashboard KPIs
- Total Customers
- Active Customers
- Churned Customers
- Churn Rate (%)

## Visualizations
- Customer Churn by Contract Type
- Customer Churn by Payment Method
- Average Monthly Charges by Churn
- Internet Service Distribution
- Average Tenure by Churn
- Filters: Gender, Contract, Internet Service

## Key Insights
- Month-to-month contracts have the highest churn.
- Customers using Fiber Optic internet show higher churn.
- Churned customers have shorter average tenure.
- Electronic check users contribute a large share of churn.
- Customers with longer contracts are more likely to stay.
